# TODO List Application

A simple and responsive TODO List web application built using HTML, CSS, and JavaScript.

## Features
- Add tasks
- Delete tasks
- Mark tasks as completed
- Simple and clean UI
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
